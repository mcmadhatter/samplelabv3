04Back to Plinky

Export both files for new audio or changed slices. Load a fresh presets backup from your synth first: the presets export contains that entire backup with this slot’s metadata updated.

Direct save first downloads a ZIP backup of the current slot and presets. It then updates the selected slot using freshly read presets from the connected drive. If the browser or bootloader rejects direct writes, use the download buttons above and copy both files manually.

Back up your Plinky first. Enter its USB drive mode, copy both exported files to the drive, wait for writing to finish, then restart with the encoder. UF2 addresses determine which slot is written; renaming a file does not move it.
Format & compatibility

For the original STM32 Plinky v3 / Plinky+ format, not Plinky 12. A slot has 2,097,152 signed little-endian PCM frames at 32,000 Hz. Slice metadata is stored in 2,048-byte journal pages in PRESETS.UF2. This editor verifies page checksums, edits the latest valid page for the chosen slot, preserves its sequence and other settings, and regenerates its waveform and checksum. Sample-only import cannot recover the recorded length without matching presets; the full 65.536-second slot is used.

Implementation checked against Plinky’s public firmware. Hardware playback has not been tested. No network calls, external libraries, or uploads. Direct drive access uses the browser folder picker when available; it does not use WebUSB. Browser stream closure does not verify physical flash contents. Wait for Plinky’s write activity to finish before restarting.
